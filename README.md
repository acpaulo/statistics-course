# Biostatistics course website

Upload the contents of this folder to the root of your `statistics-course` GitHub repository.

Enable GitHub Pages in **Settings → Pages → Deploy from a branch → main → /(root)**.

Your homepage will be `https://YOUR-USERNAME.github.io/statistics-course/`.

Chapter 1 is at `chapters/01-non-parametric.html`. The R demonstration loads WebR from its hosted runtime, so students need an internet connection to start R. Student answers can be saved in browser storage, downloaded as a text file, or printed/saved as PDF.
