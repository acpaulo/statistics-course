# Introduction to Biostatistics — course website

This folder contains the course landing page and the first two interactive lessons.

## Files

- `index.html` — course home page
- `chapters/01-mann-whitney.html` — Chapter 1: Mann–Whitney U test
- `chapters/02-wilcoxon-signed-rank.html` — Chapter 2: Wilcoxon signed-rank test

## Publish with GitHub Pages

1. Upload the contents of this folder to the root of your existing `statistics-course` repository (not the enclosing ZIP folder).
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select your main branch and the `/ (root)` folder, then save.
5. Open the Pages URL shown by GitHub.

## Running R code

The lessons use WebR to execute R code in the browser. Open the published pages over HTTPS and allow the initial WebR runtime to load. The first start may take a little longer and requires an internet connection. Test the R code boxes on the published Pages site, not only in the local file preview.

## Student notes

Each lesson has a notes area. Text is autosaved in the student's own browser storage on that device; it is not uploaded to GitHub or shared with the instructor. Students should print/save the page as PDF or copy their notes before clearing browser data or changing devices.
